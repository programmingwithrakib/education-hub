Python Operator

অপারেটর মানে হলো কিছু বিশেষ চিহ্ন, যেগুলো দিয়ে আমরা ভেরিয়েবল আর সংখ্যার উপর কাজ করাই।
এই অপারেটরগুলো দিয়ে যোগ-বিয়োগ, তুলনা করা, লজিক চেক — এসব করা হয়।
সহজ কথায়, কম্পিউটারকে হিসাব-নিকাশ আর ডেটা নিয়ে খেলাধুলা করানোর জন্য অপারেটর খুব দরকারি।

Types Of Python Operator

1. Arithmetic Operators (গাণিতিক অপারেটর)
2. Comparison Operators (তুলনামূলক অপারেটর)
3. Logical Operators (লজিক্যাল অপারেটর)
4. Assignment Operators (অ্যাসাইনমেন্ট অপারেটর)
5. Bitwise Operators (বিটওয়াইজ অপারেটর)
6. Membership Operators (মেম্বারশিপ অপারেটর)
7. Identity Operators (আইডেন্টিটি অপারেটর)
Arithmetic Operators (গাণিতিক অপারেটর)
Name Symbol Meaning Example
Addition + দুইটা মান যোগ করে 5 + 3 = 8
Subtraction - একটা মান থেকে আরেকটা মান বিয়োগ করে 5 - 2 = 3
Multiplication * গুণ করে 4 * 3 = 12
Division / ভাগ করে এবং দশমিক রেজাল্ট দেয় 10 / 4 = 2.5
Floor Division // ভাগ করে কিন্তু পূর্ণসংখ্যা রিটার্ন করে 10 // 4 = 2
Modulus % ভাগশেষ (remainder) দেয় 10 % 3 = 1
Exponent ** ঘাত (power) হিসাব করে 2 ** 3 = 8

Operator Precedence

Priority Operation Symbol Example Result
1 (Highest) Parentheses () (2 + 3) * 4 20
2 Exponent ** 2 ** 3 8
3 Multiplication / Division / Floor Div / Modulus *, /, //, % 10 / 3 3.33
4 (Lowest) Addition / Subtraction +, - 10 - 4 + 2 8

Precedence Example


(5 - 1) * ((7 + 1) / (3 - 1))
→ 4 * ((7 + 1) / (3 - 1))
→ 4 * (8 / 2)
→ 4 * 4.0
→ 16.0

এক্সপ্রেশন মানে হলো — কিছু value আর operator একসাথে মিলে একটা হিসাব বা কাজ করে, যার শেষে একটা মান বের হয়।

String Concatenation

অপারেটর স্ট্রিং-এর ক্ষেত্রেও কাজ করে. তবে এখানে সেটা “যোগ” না, বরং “জোড়া লাগানো”র কাজ করে।


	>>> 'Hello ' + 'world!'
	'Hello world!'

কিন্তু যদি স্ট্রিং আর সংখ্যা একসাথে দাও —


	>>> 'Hello ' + 5
	TypeError: can only concatenate str (not "int") to str

সমাধান — সংখ্যাটাকে আগে str() দিয়ে টেক্সটে রূপান্তর করো। —


	>>> 'Hello ' + str(5)
	'Hello 5'

অপারেটর যদি একটা স্ট্রিং আর একটা সংখ্যা পায়, তাহলে সেই স্ট্রিংটাকে বারবার রিপিট করে। —


	>>> 'Hello ' * 5
	'Hello Hello Hello Hello Hello '

Variables


		# Assigning values to variables
		x = 10          # Integer
		y = 3.14        # Floating-point number

		# Using variables in expressions
		sum = x + 5
		greeting = "Hello, " + name
		print(sum)
		print(greeting)

Rules of variable naming

  • Variable names must start with a letter or an underscore (_).
  • They can contain letters, numbers, and underscores.
  • Variable names are case-sensitive.
  • Avoid using Python keywords as variable names.
